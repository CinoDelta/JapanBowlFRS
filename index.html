A website designed to help students practice their Japan Bowl Final Round skills.


This website is designed to help students prepare for the Japan Bowl Final Round. It allows users to practice with a variety of decks, track their progress, and even upload their own decks for others to use.

Practice !

Select a deck and start practicing immediately. Keep track of your personal bests through
a local leaderboard.

Upload !

Create your own deck using the websites JSON template, or our built in deck creator (coming in version 2)

Host a Match !

Host a match for your team, and share the match code with your players. Players can join the match and compete against each other in real time.

Create Decks!

Creat your own decks using the built in deck creator (coming in version 2) or by using the JSON template provided.
