# Welcome to Japan Bowl Final Round Simulator! (Toss-up)

1. This simulator features a single player practice mode where you can upload your own custom deck with custom practice settings to try and get the best score that you can.
2. The main mode of this simulator is the Toss-up local/server mode. Create your own toss-up round with a customizable amount of questions, splitting you and your group into different teams. The same rules as the real toss-up, buzzers and all.
3. The last mode of this simulator is the Playoffs round mode. Team up with max 2 other friends local/server (or just by yourself) and tackle 30 customizable (or preset) mutliple choice questions. You have to type in the answer, and it has to match the preset correct answer in the deck (with a few spelling mistakes allowed)

Outside of the classroom and meetings, this simulator is intended to increase the amount of effective practice time for japan bowl teams.
