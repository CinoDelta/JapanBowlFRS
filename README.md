# Welcome to Japan Bowl Final Round Simulator! (Toss-up)
_
The following text explains features that are planned- not everything is implemented yet.
_
1. Asingle player practice mode where you can upload your own custom deck. Go with default practice settings for leaderboard competition, or custom settings for your own benefit.
2. A Toss-up local/server mode. Create your own toss-up round with a customizable amount of questions from a certain deck, splitting you and your group into different teams. The same rules as the real toss-up, buzzers and all.
3. The last mode of this simulator is the Playoffs round mode. Team up with max 2 other friends local/server (or just by yourself) and tackle 30 customizable (or preset) mutliple choice questions from a deck. A host will distribute points between each player. A non-host mode is planned with preset multiple-choice competitive decks pertaining to the current season.

Outside of the classroom and meetings, this simulator is intended to increase the amount of effective practice time for japan bowl teams.
